# Generative Palette A11y — visual thesis

## Direction: handwritten lab notebook

This is a studio instrument, not a corporate dashboard. It borrows the evidence
of a working artist's notebook: warm uncoated paper, graphite rules, index-card
labels, coloured-pencil marks, and a clipped test swatch. The visual language
turns an abstract accessibility check into an experiment an artist can revise.
It is deliberately single-mode: an illuminated desk/paper field makes long
colour-comparison sessions calmer and keeps the simulations legible.

## Tokens

- **Paper / background:** `#f7f0df`; **paper shadow:** `#e8dcc4`; **ink:**
  `#24211d`; **muted graphite:** `#625d54`.
- **Lab blue / primary action:** `#155e75` with white ink; **pencil red /
  warning:** `#a33b31`; **pencil green / pass:** `#236348`; **yellow tape:**
  `#e7be46`.
- Surfaces use `#fffaf0` and a `#cdbfa6` rule; all text combinations are at
  least 4.5:1. Simulations themselves retain their actual sampled colours and
  always have text labels and numeric metrics beside them.

## Type, rhythm and interaction

System serif (`Georgia`) carries notebook annotations; the self-contained
system sans stack carries controls and data for clear small labels. The scale is
12 / 14 / 16 / 20 / 30 / 44px, on a 4px rhythm. Cards are used only for
separate lab specimens (frames, pair findings, proposed fixes); most grouping
is a ruled line and generous paper margin. Controls are 44px minimum.

The primary grammar is **write → observe → adjust**: palette chips behave like
paint dabs, reports are labelled field notes, and changing a suggestion returns
the user to the original swatch with an undoable change. A transient 180ms
opacity/transform cue marks a fresh analysis. With reduced motion, results
appear immediately and all decorative movement stops.

## Original illustration plan and provenance

The hero is an original, AI-generated desktop still life: an open artist's
notebook containing abstract grid and colour studies, swatch strips and a
simple magnifier. It is explanatory atmosphere rather than a product claim.
Art direction prompt sheet: warm overhead window light, tactile recycled paper,
graphite, ink and coloured pencil; palette words “oat paper, charcoal, indigo,
vermilion, moss”; editorial 35mm top-down view; **no text, watermark, logos,
people, brands, or UI mockups**. Generated with the factory image deployment on
2026-08-28; original asset, then optimized to WebP. The footer discloses this.

The 1200×630 social preview and 180×180 touch icon are crops derived from that
same original hero, made on 2026-09-05. The two demo loop frames are
hand-authored SVG geometry using the product tokens; they show an intentionally
confusable coral/moss pair so the sample immediately produces a useful report.
